# Competition Overview

The task is to detect fluorescently labeled zebrafish embryo cell centers in 3D time-lapse microscopy, link detections across time, identify divisions, and reconstruct a lineage graph.

Primary verified sources:

- Kaggle competition and data pages.
- Organizer repo: https://github.com/royerlab/kaggle-cell-tracking-competition
- Metric docs/code in the organizer repo.

The competition is a notebook/code competition. The final inference path must write `submission.csv` at the notebook working directory and must not depend on runtime internet.

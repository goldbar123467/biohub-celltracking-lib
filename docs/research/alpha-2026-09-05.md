## First experiments

1. Fix real-data loading, exact official evaluation, graph validation and atomic
   packaging. Compare CSV-round-tripped predictions to in-memory graphs.
2. Benchmark the unchanged classical recipe with faster exact spatial searches
   on complete clips from both embryos. Report this as an engineering benchmark,
   not a tuned CV result; then freeze full embryo-held-out folds.
3. Build and run the same offline package on Kaggle's mounted examples. Measure
   runtime before spending GPU quota on learned candidates.
4. With those gates working, compare detector recall versus density and runtime
   for a bounded sparse-label detector and a reviewed teacher-label candidate.
   Keep all fitting, pseudo-label calibration and threshold selection within the
   training side of each fold. Reassess linking and divisions after detection.

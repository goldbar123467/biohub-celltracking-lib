# External Data Policy

- Use only public/free external data or pretrained weights allowed by Kaggle rules.
- Final submitted notebooks must run with internet disabled.
- Package external artifacts as Kaggle datasets or vendored repo assets.
- Record artifact URL, license, checksum, and exact use in `docs/decisions/`.
- Do not add runtime downloads to inference scripts.
- Prefer local CV proof over public leaderboard anecdotes.
